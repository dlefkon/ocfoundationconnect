# ocfoundationconnect.com — Wave 1 static site

**Business:** Orange County Foundation & Basement Connect (DBA, filed Nov 18, 2026)
**What it is:** a referral service website. It connects Orange County, NY homeowners with
ONE independent local foundation & basement waterproofing specialist. It is **not** a
contractor site: every page carries the referral disclosure, and nothing on the site
claims the business does the work, holds a contractor license, or has reviews/ratings.

Plain static HTML/CSS/JS. No frameworks, no build step, no external dependencies.
Shared assets: `/assets/site.css`, `/assets/site.js`. Pages were generated by
`build_site.py` (kept in this folder) so the shared header/footer/form blocks stay
identical — edit the script and re-run it rather than editing 23 files by hand.

## Functionality (all in `/assets/site.js`)

- **Service-area checker:** ZIP → instant in-area / out-of-area answer. The 56-ZIP
  Orange County array is sourced from ZIP-Codes.com's county list (U.S. Census ACS
  2024 data), verified Nov 18, 2026 — source cited in a comment in `site.js`.
  In-area routes to the form with the ZIP prefilled; out-of-area shows an honest
  message and no form.
- **Symptom picker** (home page): wall cracks / water in basement / bowing walls /
  musty smell or mold / sloping floors → two plain sentences each, then routes to
  `/get-help/` with the problem pre-tagged (select preset + visible tag chip).
- **Lead forms:** TCPA consent checkbox (never pre-checked), honeypot field,
  "what happens next" strip. See pending items below for the submit behavior.
